# Some database

We are going to create a relational database together.

> [!NOTE]
> This is the calm version. For all the other versions check the [main repository](../..)

## Intro

This version supports:

- Basic `WHERE` clauses on `SELECT`
- Some table metadata
- A better TUI experience

You can find all related tutorials and documentation on our [Substack](https://tiagoantao.substack.com/p/roadmap)

## Trying stuff

Have a look at the [example](example.py). Run it by doing

`uv run example.py`

The [Streamlit web interface](ui.py) version can be run like this

`uv run streamlit ui.py`
